# README artwork

The English and Korean READMEs share the dark library poster titled **oh my secondbrain**.

## Native artwork

The scene was modeled and rendered in Blender 4.3.2 with Cycles. Three architectural shelving wings, individually varied books, an open volume, drifting paper leaves, and connected light points express personal knowledge as a library of stars. The final native background is 2700 × 1350, rendered with up to 1024 samples. Editable SVG typography supplies the poster layout; the repository uses an optimized 1800 × 1120 WebP export.

Geometry, paper shading, typeset page textures and layout are original to this artwork. The paper is an authored material, not a photographic paper scan. No image-generation model or photographic paintover was used.

## Third-party material and fonts

- Wood: [White Oak Veneer](https://polyhaven.com/a/white_oak_veneer) by Jenelle van Heerden, from Poly Haven under [CC0](https://polyhaven.com/license). The native scene uses the diffuse, roughness and OpenGL normal maps with a smoked warm finish.
- Typography: Nimbus Sans and Nimbus Mono PS from [URW Base35](https://github.com/ArtifexSoftware/urw-base35-fonts), distributed under AGPL-3.0 with the font exception. Fonts are rendered into this image; font binaries are not included in the repository hero asset.
